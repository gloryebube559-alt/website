# CodeWave Website

A modern landing page for a digital product and web design studio.

## Run locally

Open `index.html` in a browser, or serve it with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – website structure and content
- `styles.css` – all styling and responsive layout
- `script.js` – mobile navigation and form interaction

## Deployment

This static site can be hosted on GitHub Pages, Vercel, or Netlify.
